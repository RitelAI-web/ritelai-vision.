# RitelAI MT5 Connector — demo bridge preflight

## Build 0.2.0
- Demo-account gate and broker-name detection (Exness / Versus Trade).
- User-selected account profile: Exness Standard Cent or Versus Trade Standard.
- XAUUSD symbol resolution, including broker suffixes.
- One-time pairing through the Supabase Edge Function.
- Stores the device token locally in the MT5 terminal Files folder.
- Sends heartbeat and polls the signal inbox.
- Displays inbox status only; it never executes market or pending orders.

## Install
1. In MT5 desktop, open MetaEditor (F4).
2. Open `mt5/RitelAI_Connector_Preflight.mq5` from this repository.
3. Compile. This source has not been compiled in MetaEditor in this environment.
4. In MT5: Tools > Options > Expert Advisors, allow WebRequest for:
   `https://brfssdpplapefjmxnpft.supabase.co`
5. Attach the EA to an XAUUSD chart on a DEMO account only.
6. Select the matching profile input and enter a fresh one-time pairing code generated by the authenticated RitelAI website.
7. The EA pairs once, saves its token at `MQL5/Files/RitelAI_MT5_device_token.txt`, then sends heartbeat and polls.

## Security and limitations
- Never enter broker passwords, Supabase service-role keys, or personal access tokens into the EA.
- The device token is a credential. Protect the local MT5 Files folder and revoke the device if exposed.
- Pairing requires an authenticated RitelAI user with active Enterprise entitlement.
- Broker/profile checks use terminal company/server text plus the selected profile; MT5 cannot independently prove the Standard Cent / Standard subtype.
- This build does NOT execute, modify, or close trades. Semi-Auto approval and Auto execution remain disabled.
- Before execution is enabled, harden pairing atomicity, signal claiming/idempotency, entitlement schema verification, risk limits, daily loss lockout, stale-signal checks, emergency stop, and demo execution tests.
